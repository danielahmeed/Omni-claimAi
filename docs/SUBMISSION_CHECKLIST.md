## 3. Numbers you can measure and defend

Run these on the deployed app with Gemini live, then quote them on slides 2 and 12:

| Metric | How to measure |
| --- | --- |
| Median analysis time | Run the four presets a few times each. The header shows **Median analysis time** over all Gemini analyses. Repeat runs are correctly flagged as reused photos, but their timing still counts. The Analysis log of each claim shows how long the Document AI and Gemini steps took. |
| Routing accuracy on the test scenarios | On fresh data, run each preset once and count how many were routed as expected (shown on each preset card). |
| Unsupported charges flagged | The header metric, for example "$7,200 of $8,450 disallowed on the inflated bill". |
| Reused-photo detection | The reused-photo preset matches the earlier claims with a hash distance of 0 of 64 bits. |
| Engineering quality | 90 automated tests (`python -m unittest discover -s tests`). The Gemini and Document AI clients are tested against fake endpoints, and Firestore and Cloud Storage against official emulators. |

Say "on our test scenarios" rather than implying production accuracy.
